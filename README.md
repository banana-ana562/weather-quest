# An Embedded Weather Quester

An IoT client called "An Embedded Weather Quest". An embedded system with WiFi capability. User request is accepted from a computer serial terminal. 
The request is sent to openweathermap.org, and an open web server for weather information on any city. The response will be received and will display
the requested city weather information on two display devices:
1. Computer serial terminal
2. Color LCD

The following components were used for this project:
1. TM4C123 LaunchPad
2. CC3100 Booster Pack
3. An internet access point (hotspot)
4. ST7735R 128x160 Color LCD
